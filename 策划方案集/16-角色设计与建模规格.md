## 一、设计约束(先立红线,再设计角色)

| 约束 | 出处 | 含义 |
|------|------|------|
| **主技能必须 10 秒内学会** | 需求 | 主技能一律是**对抗型**:一记特殊攻击、一次反击、或一层防御。一句话说完,按一下就懂 |
| **货量恒定,永不补货** | 《03》 | 全场库存单向流失,**本作不设补货机制**。任何技能不得凭空增加库存或复活货位 |
| **强度差≤15%** | 《14·十》 | 主技能可以打人,但必须以**自身失衡**为代价支付;被动若给数值,幅度受本节1.4 约束 |
| **不动大妈AI** | 《14·七》注 | 操纵 `granny.gd` 仇恨的技能(人情牌/围观效应)首发一律不做 |

> **修订3 放宽了两条原红线**(记录在此以免后人误判):
> 原"零基础数值差异"与"被动一律不给数值"因赵冬梅的机动型被动而放宽为
> **"主动技能零基础数值差异 + 被动数值受§1.4 上限约束"**。代价是必须新增一条
> 数值红线(§1.4),否则角色系统会重新滑向"必选角色"。

### 1.1 三角色的分工:攻 / 防 / 夺

主技能覆盖对抗的三种基本答案,任何一个都不能替代另两个:

| 角色 | 主技能一句话 | 对抗身位 |
|------|------------|---------|
| **赵冬梅「铁腿」** | 按一下,飞出去撞人 | **主动进攻** |
| **马德胜「老码」** | 按一下,扎住不动,谁撞我谁倒 | **防御反击** |
| **李洋「上链接」** | 按一下,一钩子把对方的货抢过来 | **直接夺取** |

### 1.2 被动:两条信息 + 一条手感

| 角色 | 被动 | 类型 | 与自己主技能的关系 |
|------|------|------|-------------------|
| 赵冬梅 | **压弯**:转向机动+ 体力耐久 | **手感型** | **前置**:让她跑得到、撞得着、撞完还有体力跑 |
| 马德胜 | **余光**:威胁方向预警 | 信息型(掌控"人") | **Combo**:看见谁冲过来 → 提前扎马步 → 反杀 |
| 李洋 | **爆款嗅觉**:货在谁车里 | 信息型(掌控"车") | **Combo**:看见货在谁车里 → 追上去一钩子抢过来 |

**「余光」为什么必须给马德胜**:他的主技能是**纯反应型**——扎马步只有在"有人正要撞我"
时才有价值,但2秒定身又意味着**猜错就是白白挨打**。没有预警的防御反击是赌博;
配上余光,它才成为一门可练的技术。这是三个被动里咬合最紧的一组:
**箭头亮起→ 按 Ctrl → 对方自己倒地**,一套连招闭环。

反过来看,赵冬梅原先拿着余光是浪费:她是主动进攻方,**是她在追别人**,
"谁在冲我"对她意义远小于"我能不能追上"。改成机动型被动后,她的被动与主技能同向。

### 1.3 统一的代价货币:失衡值

三个主技能都用**自身失衡**付账(赵 +20 / 马 定身 2s / 李 +25)。
理由:失衡是《05》里玩家最先学会的资源,用它做统一代价,玩家不需要理解新机制
就能感觉到"这一下有风险"。这也让三个技能天然不可连发——付不起。

### 1.4 【新增红线】被动数值上限

赵冬梅的「压弯」是首个提供常驻数值的被动,必须立刻立好上限,否则后续角色会攀比:

| 约束 | 数值 |
|------|-----|
| 单项数值增益幅度 | **≤ 25%** |
| 可触碰的参数类别 | **只允许"机动性"与"资源耐久"**(转向、抓地、体力消耗) |
| **禁止触碰** | 移速上限、失衡阈值、载重容量、伤害/失衡输出、搜货与偷窃时长 |
| 综合强度贡献 | 单个被动 ≤ **8%**,与装备养成叠加后仍须满足《14·十》的 ≤15% |

**为什么移速被明确禁止**:移速是本作最强的隐性数值(决定谁先到爆款专区、
谁能逃出闸机拥堵)。给赵冬梅的是**"转弯不用减速"与"能一直冲"**,
而不是"直线跑得更快"——前者是驾驶技术的回报,后者是无条件碾压。

### 1.5 与外貌自定义的关系(解掉《14·十二·5》的待拍板项)

**角色决定款式,玩家配色决定服装主色。**
`PlayerProfile` 的 8 色作用于 `M_Cloth_Primary`;角色专属配件(护目镜/护腰/补光灯)
用固定色 `M_Accent`,不参与染色——"谁"(颜色)与"什么角色"(轮廓)两条识别通道分离。

## 三、赵冬梅「铁腿」· 退役短道速滑运动员

> "超市过道就是弯道。内切、贴边、卡位——规则我比谁都熟。"

### 3.1 主技能:贴地冲撞(`Ctrl`,CD 20s)

**一句话:按一下,朝镜头方向飞出去撞人。**

0.2 秒下蹲蓄力(全场可见),随后 0.45 秒内沿镜头方向突进 **5 米**(约 11 m/s):

| 撞到| 效果 |
|------|-----|
| 徒步玩家 / 大妈 | **+55 失衡**,连人撞飞(冲量按 11 m/s 结算) |
| 正在推车的人 | 对方 **+40 失衡**,其车斗甩货 **20%** |
| 无人看管的购物车 | 车被撞开并甩货,可用来"清场" |
| **她自己在推车时** | 连人带车突进,车头撞击按《05》表结算并**×1.5**(车侧 45→67,冲刺 60→90) |
| 撞到货架/墙 | 无伤害,但进入硬直 |

**代价(两条)**:

- 无论命中与否,**自身 +20 失衡**
- **落空则 1.2 秒硬直**(收不住脚,双手乱抓,不能移动/肘击)——这是对手的处刑窗口

表现:脚下双道橙色速度残影 + 冰刀"嚓嚓"声,手部姿态切`"speed"`(双手背在身后
速滑摆臂),命中时 `float_text` 打 "内切!!"。

代码落点:`player.gd` 新增突进状态机(复用 `push_velocity` 与 `apply_motion`);
撞击结算复用 `hit_by_cart()` / `add_imbalance()`,需给 `add_imbalance` 增加攻方系数参数。

**为什么它10 秒就能学会**:它就是一个"冲撞键"。没有窗口期管理、没有增益条,
按下去人就飞出去——命中很爽,落空很惨,两次就学明白了。

### 3.2 被动:压弯(手感型)

**转弯不用减速,而且一直冲得起。** 两个分项,都只作用于"机动性"与"体力耐久"
(《一·1.4》允许的两类),**不含任何移速、载重、失衡或输出增益**。

#### A · 转向机动

| 项 | 基准值 | 赵冬梅 | 代码落点 |
|----|-------|--------|---------|
| 推车转向力 | `DRIVE_STEER 110.0` | **×1.25** | `player.gd:162` |
| 侧向抓地(抗漂) | `LATERAL_GRIP 6.0` | **×1.2** | `cart.gd:9` |
| 低速转向下限 | `steer_eff` 最低 0.12 | **0.20**(慢速也掰得动车头) | `player.gd:160` |
| 徒步擦墙 | 贴墙滑行会明显失速 | 保留 **90%** 速度 | `actor_base.gd:apply_motion()` 滑行分支 |

#### B · 体力耐久

| 项 | 基准值 | 赵冬梅 |
|----|-------|--------|
| 冲刺消耗 | 22/秒 | **16.5/秒(-25%)** |
| 连续冲刺时长 | 约 4.5 秒 | 约 **6.1 秒** |
| 体力回复 | 15/秒 | **不变**(不给回复加成) |
| 肘击耗体力 | 4/次 | **不变**(不碰输出侧) |

表现:过弯时内侧脚下擦出短促火花与"嚓"声(速滑压弯的听觉锚点),
体力条在她身上显示为**冰蓝色**而非通用黄色——让"这人耐力不一样"被一眼看见。

设计意图:她是唯一必须**贴身作战**的角色,而贴身的前提是**追得上、拐得进、
撞完还有体力跑**。这条被动不提高她的撞击强度,只提高她"把自己送到能撞的位置"的能力——
主技能负责那一下,被动负责创造那一下的机会。

**为什么不给移速**:见《一·1.4》。直线更快是无条件碾压,转弯更快是驾驶技术的回报——
不会开车的人拿到「压弯」也只是撞货架撞得更快。

### 3.3 平衡自查

- 突进有 0.2s 可见前摇+ 全场可见残影,对手可用「稳住」(空格)正面接下
- 每次出手 +20 自身失衡⇒ 连续三次进攻她自己就到倒地边缘,天然节流
- 收银通道内 `immune` 优先级最高,冲不进免战区抢人
- **被动强度估算**:体力 -25% 折算综合强度约 +5%,转向增益约 +3%,合计 **≈8%**,
  处在《一·1.4》上限;因此她的主技能**不得再获得任何数值加强**,
  若实测偏强,优先从"+20 失衡"上调到 +25 来找平,而不是削被动(被动是她的手感底子)

## 四、马德胜「老码」· 前物流仓库保管员

> "货不是塞进去就算完,得码。撞我?我这腰板三十年了。"

### 4.1 主技能:扎马步(`Ctrl`,CD 22s,持续 2 秒)

**一句话:按一下,扎住不动,谁撞我谁倒。**

双脚一沉、双手前撑,2 秒内:

| 效果 | 说明 |
|------|-----|
| **免疫撞击失衡** | 购物车撞击、肘击一律 0 失衡(物理冲量仍在,人会被推动) |
| **车斗锁死** | `spill()` 与 `eject_random_item()` 直接返回,一件都甩不出去 |
| **反击** | 撞上来的购物车,其**攻方**按撞速获得 **30-50 失衡**(2.5 m/s→30,8.8 m/s→50)并被反向弹开 |
| 表现 | 车身与人脚下亮一圈黄色"重物"标记,反击命中打 "码得住!!" |

**代价(一条,但很重)**:

- **2 秒内人车完全定身**,结束后 0.8 秒缓速
- **技能期间照样能被偷**:按住 E偷车(`take_top_item()`)完全不受影响

代码落点:`actor_base.gd:add_imbalance()` 的 `braced` 分支扩展;`cart.gd:317 spill()` /
`cart.gd:303 eject_random_item()` 加锁标志;反击走 `apply_central_impulse` + 对攻方
`add_imbalance`。

**与通用「稳住」的区别(必须一眼分清)**:

| | 稳住(空格,全角色) | 扎马步(Ctrl,马德胜) |
|---|---|---|
| 时长 | 1 秒 | 2 秒 |
| 能否移动 | 能(减速 55%) | **完全定身** |
| 保护范围 | 只免自己的撞击失衡 | 免撞击与肘击 + **车里的货** |
| 反击 | 无 | **反弹 30-50 失衡给攻方** |

**为什么它10 秒就能学会**:第一次被人撞、结果对方自己倒了,就懂了。
难的不是理解,是**敢在打烊冲刺的通道里停2 秒**——这是他的深度所在。

### 4.2 被动:余光(信息型,掌控"人")——**与主技能构成 combo**

**屏幕边缘的威胁方向预警。**

| 条件 | 表现 |
|------|------|
| 15m 内有**冲刺中且大致朝向你**的玩家或大妈 | 屏幕对应方向边缘浮出红色三角箭头,越近越亮 |
| 该威胁 **0.4 秒后**将撞到你 | 箭头**闪白** + 一声短促"嗤" |
| 威胁转向或减速 | 箭头立即消失 |

落点:`hud.gd` 新增边缘指示层;判定用现有 `is_running()` / `cart.linear_velocity`
与朝向点积(与《05》撞击判定同一套口径,不引入新规则)。

#### 4.2.1 这是首发三人里唯一的 combo

```
边缘箭头亮起(还有 ~1.5 秒)
    └→箭头闪白(0.4 秒后命中)
         └→ 按 Ctrl 扎马步(瞬发)
              └→ 对方撞上来:自己吃 30-50 失衡 + 被弹开,而马德胜的货一件没掉
```

**为什么这个组合必须成立**:扎马步是纯反应型技能——2 秒定身,猜对了反杀,
**猜错了就是站着白挨打**。没有预警的防御反击只是赌博,不是技术。
余光把它变成"看得见的机会窗口",于是马德胜从"耐揍的胖老头"升级为
**擅长在拥堵通道里等人撞上来的老江湖**——这个角色幻想才是完整的。

而且这条被动**只给信息不给数值**:箭头告诉你有人来了,**按不按、什么时候按、
按早了2秒定身正好被第二个人撞**,全是玩家自己的判断。

### 4.3 被动移交说明(修订3)

- 「余光」**原属赵冬梅**,现移交马德胜。理由:赵冬梅是主动进攻方,**是她在追别人**,
  "谁在冲我"对她的价值远低于"我能不能追上";而马德胜没有预警就没法用主技能
- 「心里有本账」(全场剩余库存)**原属马德胜,现转入候选池**,不在首发实装。
  一人只能有一个被动,而余光与他的主技能咬合更紧。
  该被动仍然是好设计(货量恒定 ⇒ 库存数字只减不增 ⇒ 天然是一份倒计时),
  建议留给未来的第 4 角色(仓储/情报向),见第十节待拍板 5

### 4.4 平衡自查

- 定身 2 秒 + 车身可见特效 = 明确的可打击窗口,信息对全场公开
- 反击只对"主动撞他的人"生效,不能主动攻击,不会变成移动炮台
- 余光只在**对方冲刺且朝向你**时触发:慢速贴上来偷车(`take_top_item()`)**不会**报警——
  这与"扎马步不防偷"是同一条弱点的两面,偷窃始终是对付他的正解
- **combo 强度风险**:预警 + 必定反击可能让"撞人"这个核心动词变得畏手畏脚。
  若实测对抗频率下降,先把反击从"必定"改为**仅反击冲刺撞击**(见待拍板 2),
  而不是削弱余光——预警是他的乐趣来源

## 五、李洋「上链接」· 带货主播

> "三、二、一——上链接!哎这位大哥手里那个,让一让,那是我们家的库存。"

### 5.1 主技能:上链接(`Ctrl`,CD 25s)

**一句话:按一下,一钩子把对方的货抢到自己手上。**

举起自拍杆朝镜头方向一钩,判定为前向 **3.5 米、±45° 锥形**,0.3 秒出手:

| 命中 | 抢走什么 |
|------|---------|
| 玩家(手上有货) | 手中**随机 1 件**,直接飞到自己手上 |
| 玩家(手上空、正推车) | 其车斗**最上层 1 件**(等价`take_top_item()`,但瞬发) |
| 大妈 | 她抱着的 1 件(会触发她的追讨行为,《06》既有逻辑) |
| 自己手已满 | 商品落在自己脚边(仍然完成了"断人补给") |
| 目标在收银通道内 | **无效**(`immune` 优先) |

**代价(两条)**:

- **自身 +25 失衡**(重心前倾,一钩子把自己也带歪)
- **被抢方获得 4 秒追踪标记**:他能穿墙看到李洋的位置与被抢商品图标

代码落点:`actor_base.gd:try_elbow()` 的锥形判定可直接复用(改判定距离与结算);
夺取走 `drop_one_held()` + `take_item()`;`cart.gd:take_top_item()` 已存在;
追踪标记复用 `item.gd` 的 `ping_shell` 与 `cart.gd:highlight_mesh` 的显示层。

**为什么它 10 秒就能学会**:抢东西是本作最原始的动词。它不需要任何解释——
唯一要学的是"抢完得跑",而这一课由那4 秒追踪标记免费教给你。

### 5.2 被动:爆款嗅觉(信息型,掌控"车")——即需求中点名的那条

**全场任何购物车里装有你"还缺"的清单商品时,该车穿墙亮红壳,车顶浮出商品名。**

| | 通用版(全角色,现状要削弱) | **爆款嗅觉**(李洋专属) |
|---|---|---|
| 距离 | **12 米内**(新增限制) | **全场无限制** |
| 穿墙 | 是 | 是 |
| 信息量 | 只有红壳(不知道是哪件) | 红壳 + **车顶浮出具体商品名** |
| 装入提示 | 无 | 有人把你缺的货装进车时,**全场提示一次** |

落点:`main.gd:_apply_highlights_local()` 与 `_hot_carts_for(idx)` 加距离参数;
车顶商品名复用 `cart.gd` 现成的 `alert_label`(被偷提示"!")那一层 `Label3D`。

> **⚠ 这是本次修订唯一需要动通用层的地方。**
> 现在的"杀意感知"(《05·三》末)是**全员被动**、无距离限制。要让它成为角色特色,
> 通用版必须让位。本文采取**削弱而非删除**(降为 12 米)的折中:
> 保留全角色"贴近了能看出这车有我的货"的基础体验(否则新手会觉得信息突然瞎了),
> 把"隔着半个超市就知道货在谁车上"留给李洋。是否彻底删除通用版,见第九节待拍板 3。

设计意图:被动告诉他**货在谁车里**,主技能让他**把货钩过来**——
信息与手段构成完整闭环,这是三人里唯一"被动直接喂主技能"的角色,也是他的定位:
不跑图、不硬碰,专门收割别人的劳动成果。

### 5.3 平衡自查

- 夺取上限 **1 件/次**,CD 25s,一局约 12 次机会;且 +25 自身失衡使他无法边抢边打
- 4 秒追踪标记是被抢方的**免费反制**:他抢的是货,付出的是位置
- 不能抢已扫码商品、不能进免战区抢人(《05·五》)——不会破坏"过闸即安全"的契约
- 被动只给信息:知道货在谁车里,还得自己追上去

### 7.3 实装顺序(按风险从低到高)

1. **马德胜**——效果全落在已有的 `braced` / `spill` / `eject_random_item` 上,

2. **赵冬梅**——需要新的突进状态机 + 给 `add_imbalance` 加攻方系数,是唯一动战斗公式的
3. **李洋**——涉及物权转移与联机权威,风险最高,放最后

被动的实装顺序:

1. **「爆款嗅觉」**——只改现有高亮函数的距离参数,最快
2. **「压弯」**——纯参数乘算(`DRIVE_STEER`/`LATERAL_GRIP`/`steer_eff`/冲刺耗),

## 八、统一建模规格(三角色共用)

### 8.1 造型语言

**二头身 + 独立悬浮双手**(参考《胡闹厨房》),三条本作专属取舍:

| 要点 | 规格 | 理由 |
|------|-----|------|
| 头身比 | 总高 1.70m,头高 0.66m(≈2.6 头身) | 现有碰撞胶囊高 1.70m 不改;头再大会遮挡第三人称视野与货架 |
| **无手臂** | 肩部封闭,**完全没有手臂与肩袖**,双手是脱离身体漂浮的球状连指手套 | 直接对应 `actor_base.gd` 用两个小球做手、靠位置 lerp 驱动的现有实现 |
| 腿 | 短粗腿,鞋底离地 0,行走用整腿摆动 | 保留奔跑的滑稽感;不做脚趾 |
| 轮廓识别 | 每人必须有 **1 个 3 米外可辨的剪影特征** | 联机 6 人混战时的辨认成本 |
| 面部 | 只有眼睛与极简嘴,**不做鼻子几何** | 现有白盒的"鼻子"是朝向指示,正式模型由头部造型承担朝向 |

剪影特征:赵冬梅=头顶挡风镜+束发;马德胜=圆顶布帽+圆肚+腰后护腰板;
李洋=挂脖补光灯环+高举的自拍杆。

### 8.2 尺寸与锚点表(单位:米,与现有代码一致)

| 部件 | 尺寸 | 锚点 y | 备注 |
|------|-----|-------|------|
| 碰撞胶囊(不建模) | r0.32 / h1.70 | 中心 0.85 | `build_body()` 现值,**模型必须以此为准** |
| 头 | Ø0.62,高 0.66 | 中心 1.37 | 略前倾 3° |
| 躯干 | 0.52 × 0.30 × 0.62 | 中心 0.73 | 圆角方体,肩部封闭 |
| 腿(×2) | Ø0.17,长 0.42 | 髋 0.42 | 间距 x±0.13 |
| 鞋(×2) | 0.20 × 0.12 × 0.28 | 中心 0.06 | |
| **手(×2,独立对象)** | **Ø0.20 球状连指手套** | **1.92 / x±0.42** | 原点必须在球心;对应 `hand_l/hand_r` 初始位 `(±0.42, 0.92, 0)` |
| 名牌位(不建模) | — | 2.15 | `Label3D` 挂点,头顶留空,别放高帽子挡住 |
| 朝向 | **-Z 为正面** | — | 与 Godot 及现有 `nose` 位置一致 |

> 手部1.92 是模型原点在**脚底**时的绝对高度;若按现有代码把手做 `body_root`
> 子节点,则用相对坐标 `(±0.42, 0.92, 0)`。两套只差一个 1.0 的根偏移,导出前确认。

### 8.3 拆件与命名(直接决定能否零改代码替换白盒)

```
Char_<id>/            # 根,原点在脚底正中,-Z 朝前
├─ Visual/            # 身体总成(不含手)
│  ├─ Head
│  ├─ Torso
│  ├─ Legs
│  └─ Accessory       # 角色专属配件(挡风镜/护腰/补光灯环)
├─ HandL# 独立网格,原点在球心
└─ HandR
   └─ Prop_Stick      # 仅李洋:自拍杆,挂在右手下,技能出手时前伸
```

`HandL/HandR` **不得是 `Visual` 的子级**,也不得绑到手臂骨——它们由代码每帧
`lerp` 位置(`_update_hands()` 的姿态表:idle/push/channel/carry/brace/speed)。
李洋的自拍杆是 `HandR` 的子级,随手运动;**杆长 0.75m**,朝 -Z,收起时贴身。

骨骼(可选,首版可纯程序驱动):`Root → Hips → Spine → Head` + `Leg_L/Leg_R`,
**不建手臂骨**。若提供动画,只需 idle / walk / run / down(倒地) 四条。

### 8.4 材质槽(必须严格三槽)

| 槽名 | 用途 | 是否染色 |
|------|-----|---------|
| `M_Cloth_Primary` | 服装主体(队服/布衫/花衬衫) | **是**,由 `PlayerProfile.color()` 驱动 |

| `M_Accent` | 角色专属配件与手套 | 否,角色固定色 |

(`StandardMaterial3D` + `albedo_color`)统一。AI 生成若带贴图,导入后一律换纯色,只留几何。

## 九、AI 建模 Prompt

### 9.1 使用方法(先读这段,能省掉 80% 返工)

**关键坑:所有主流文生3D/图生3D 模型都会自动给角色加手臂。**
硬对抗的做法是**分件生成**:

1. **第一遍**只生成**无手臂的身体**(prompt 里反复强调 armless / no arms / shoulders sealed)
2. **第二遍**单独生成一只**球状连指手套**,复制镜像成左右手
3. 李洋的自拍杆**第三遍单独生成**(细长物件与角色同批生成极易糊成一团)
4. 在 Godot 里按 §8.3 组装、按 §8.2 对齐锚点、按 §8.4 换纯色材质

若走"图生3D"(推荐,可控性高得多):先用下面的 prompt 出正交三视图
(正面/侧面/背面,白底,同比例),再喂给 Tripo / Hunyuan3D / Meshy 之类的图生3D。

## 十、待拍板问题

1. **赵冬梅的+20 自身失衡是否够狠?** 她现在有了机动型被动(转向 +25%、体力 -25%),

   不敢撞。若实测对抗频率明显下降,把反击从"必定"改为**仅反击冲刺撞击**
