# 07 · 地图与场景设计

> 项目:疯抢星期五 | 文档集v1.0 | 对应游戏版本v0.13 | 2026-08-06 | 状态:已立项

## 一、总体布局(约56×42米室内)

```
        北墙
  ┌───────────────────────────┐
  │ 生鲜冷冻区      家电区     │   四角分区:各2排长货架(行距≥4.2米)
  │ (含3座冰柜)   (含4座大件堆) │
  │                            │
  │      ★黑五爆款专区★       │   ← 地图正中:4座金色发光展台
  │                            │      全部必需品陈列于此,四面开阔
  │ 日用百货区    零食玩具区    │
  │ (含堆头)      (含堆头)     │
  │ ┌收银区┐                  │
  │ │2条通道│      入口×2      │   南侧:双门入口 + 收银区 + 西侧"出口"
  └─┴──────┴──────────────────┘
   ↓出口(NPC结算后离场豁口)
```

- **分区固定、具体货位每局随机**:玩家可积累"区域直觉"但每局仍需实地侦查
- 过道宽度4.2-5.3米:双车会车、人群穿行无卡点;冰柜/堆头/大件堆全部布置在开阔侧翼,不占过道

## 二、中央爆款专区(冲突设计核心)

- 4座金色自发光展台呈菱形分布于主通道十字路口,头顶"★黑五爆款专区★"大灯牌
- **全部6种必需品(高价值高折扣)集中陈列于此**:必然争抢发生在最开阔、最适合冲刺撞击、无处可躲的中心广场
- 对所有出生点基本等距——开局冲刺抢爆款即第一波遭遇战

## 三、货架形式(4种)

| 形式 | 规格 | 分布 |
|------|------|------|
| 长排货架 | 10米×2层×两面,32货位 | 每分区2排 |
| 卧式冰柜 | 4米顶部开口取货 | 生鲜区3座 |
| 促销堆头 | 1.7米矮托盘,4货位 | 日百/零食侧翼各2座 |
| 大件地堆 | 木托盘 | 家电区侧翼4座(电视/跑步机) |

分区招牌为**自发光灯牌**(彩色底板+大号白字),远处一眼可辨。

## 四、湿滑地面(动态地形)

三种来源,全部有寿命,消失前3秒缩小蒸发,配醒目自发光"!!小心地滑!!"立牌:

| 来源 | 数量/频率 | 寿命 |
|------|------|------|
| 开局随机水渍 | 3块(避开货架的开阔位) | 45-75秒随机 |
| 保洁拖地 | 每55-85秒1块+广播 | 25秒 |
| 玩家水瓶 | 右键技能 | 12秒 |

数值效果见《05》;满载车过水≈灾难。湿滑地面因此成为**流动的战术地形**。

## 五、收银区与出口

- 2条自助收银通道(全程开放):围栏走廊+南北双闸机+收银带,规则详见《08》
- 西南墙体开5米**"↓出口↓"豁口**(绿色大灯牌+地贴):NPC结算后由此驶离消失;防止完成者堆积堵死收银口
- 外围一圈防坠围栏把门外檐廊围成门厅;三重兜底(人/车/商品坠落自动拉回入口)

## 六、随机化与确定性

- 单机:每局全随机
- 联机:世界由**共享随机种子**生成——货位、清单、大妈配色清单、水渍位置各端完全一致(联机架构详见《10》)
