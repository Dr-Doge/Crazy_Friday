# 11 · 教学关与开发者模式

> 项目:疯抢星期五 | 文档集v1.0 | 对应游戏版本v0.13 | 2026-08-06 | 状态:已立项

---

## 一、教学关卡

开始界面独立入口。干净卖场(无NPC、计时冻结、无事件)+入口旁一辆练手无主购物车;屏幕上方绿色大字分步指引,**每步检测实际完成才推进**:

| 步骤 | 内容 | 通过条件 |
|------|------|----------|
| ① | WASD移动+鼠标视角 | 移动超5米 |
| ② | F 抓住购物车 | 挂接成功 |
| ③ | W/A/D/S 驾驶 | 推行10米 |
| ④ | Shift 冲刺 | 冲刺累计1秒 |
| ⑤ | F停车→长按E搜货架 | 手中有商品 |
| ⑥ | 走回车旁按E装车 | 车斗有商品 |
| ⑦ | 长按E偷练手车 | 偷取成功 |
| ⑧ | 试用三技能 | Q/右键/空格各用一次(逐项打✓) |
| ⑨ | 推车进收银通道扫码 | 结算完成→"🎓教学完成"→回主菜单 |

覆盖"搜-抢-撤"全流程与全部技能,时长约2-3分钟。

## 二、开发者模式

- **入口**:开始界面"开发者选项"区 + 游戏内F1面板(联机中禁用防不同步)
- **NPC数量滑块**:0-10实时增删(减员时大妈连人带车移除、货物落地不灭失;增员按出生点补齐,清单照常与玩家重叠)
- 0人=纯净驾驶/物理调参场;10人=收银口与爆款区压力测试

## 三、调试键

| 键 | 功能 |
|------|------|
| T | 快进1分钟(测打烊链路) |
| F3 | 立即触发限时特价 |
| F4 | 给自己拉满失衡(测倒地/甩货) |

## 四、自动化测试基建(工程侧)

- `WHITEBOX_SHOT=<png>`:运行约2秒自动截图退出(可视化回归)
- `WHITEBOX_AUTOSTART=1`:跳过开始界面直接单机开局;无头运行默认直接开局
- 联机四件套见《10·七》
- 常规验证流:无头全场模拟(打烊/结算/离场全链路零报错)+截图核对+多实例联机冒烟;数值旋钮集中在各脚本顶部常量,便于快速调参
