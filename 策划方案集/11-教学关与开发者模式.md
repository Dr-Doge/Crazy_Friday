# 11 · 教学关与开发者模式

> 项目:疯抢星期五 | 文档集v1.6 | 对应游戏版本v0.18.2（开发中） | 2026-08-14 | 状态:已实装

---

## 一、教学关卡

旧版“正式卖场中九步大字指引”已废弃。教学入口现在构建独立 `TutorialRooms` 地图，不生成正式卖场、普通NPC、随机库存、特价、水渍、打烊计时与正式收银通道。

| 房间 | 主题 | 核心验收 |
|------|------|----------|
| 01 | 移动与购物车 | 徒步75°第一人称、WASD/鼠标视角、F抓车切换第三人称、驾驶10米、Shift冲刺1秒 |
| 02 | 拿货与装车 | 货架陈列面朝入口；白点锁定、右键放大、长按E拿货；先自然装车，再故意拿错占满双手的大件并用R快速丢弃；Q找货雷达 |
| 03 | 偷窃与基础战斗 | 长按E偷无主车并装入己车；训练黄牛走来偷走玩家车内商品并返回原位；肘倒对手、夺回商品、Ctrl稳住挡车 |
| 04 | 商品道具与角色技能 | 训练商品稳定预置于车斗；轮盘选择、砸人1.5倍/砸车1.0倍、落点效果、电击定身、三角色技能分支 |
| 05 | 综合结业小卖场 | 自由凑齐货架/无主车/竞争者三件货，推车进绿色收银区完成结业 |

所有教学货架的取货面均朝向玩家进入方向，减少绕架和误瞄。R键不再被当作需要死记的孤立操作：玩家先完成一次符合直觉的装车，再拿起一个占满双手、并非清单目标的大件，自然形成“腾出双手”的丢弃需求；若仍按习惯把练习大件装车，系统会把它退回手中并重新提示按R，不会让流程卡死。

四道实体门关闭时保持红色并启用碰撞；本房真实玩法条件完成后变绿、向上升起并同时关闭碰撞。门不参与相机近景LOD，避免靠近时被误隐藏。`F2` 可重置当前房间，不需重载整张地图。完整设计见[《18·串联房间式教学关重做方案》](18-串联房间式教学关重做方案.md)。

## 二、开发者模式

- **入口**:开始界面"开发者选项"区 + 游戏内F1面板(联机中禁用防不同步)
- **NPC数量滑块**:0-10实时增删(减员时大妈连人带车移除、货物落地不灭失;增员按出生点补齐,清单照常与玩家重叠)
- 0人=纯净驾驶/物理调参场;10人=收银口与爆款区压力测试

## 三、调试键

| 键 | 功能 |
|------|------|
| T | 快进1分钟(测打烊链路) |
| F3 | 立即触发限时特价 |
| F4 | 给自己拉满失衡(测倒地/甩货) |

## 四、自动化测试基建(工程侧)

**一键入口**:`tools/smoke_test.ps1`(判定标准:退出码0 + stderr 全空 + 期望里程碑齐全)

| 模式 | 命令 | 覆盖 |
|------|------|------|
| 快速冒烟 | `-Mode all` | 单机 + 五房教学自动毕业 + 联机,约1 分钟 |
| 全场模拟 | `-Mode single -Full` | 打烊→宽限→结算→NPC离场全链路,约5.5分钟 |
| 满员联机 | `-Mode mp -Clients 5` | 1主机+5客户端,校验座位不重复与同步 |

**环境变量钩子**:

| 变量 | 作用 |
|------|------|
| `WHITEBOX_AUTOSTART=1` | 跳过开始界面直接单机开局(无头运行默认如此) |
| `WHITEBOX_TUTORIAL=1` | 无头直接进教学关 |
| `WHITEBOX_TUTORIALTEST=1` | 自动推进五房门禁/检查点/结业，输出 `RESULT=PASS/FAIL` |
| `WHITEBOX_TUTORIAL_PREVIEW=<0-4>` | 可视化调试时直接预览指定房间，配合 `WHITEBOX_SHOT` |
| `WHITEBOX_NPC=<0-10>` | 指定大妈数量 |
| `WHITEBOX_QUIT_ON_END=1` | 对局结算完毕自动退出(无头下游戏时间=真实时间,靠帧数卡全场不可靠) |
| `WHITEBOX_SHOT=<png>` | 运行约2秒自动截图退出(可视化回归) |
| `WHITEBOX_CHAR=<zhao\|ma\|li>` | 指定单人/教学局的角色,便于逐个角色跑回归 |
| `WHITEBOX_CHARTEST=1` | 角色技能自检(三主动+三被动),打印 `RESULT=PASS/FAIL` 后退出 |
| `WHITEBOX_PHYSTEST=1` | 车斗物理压力测试,打印 `RESULT=PASS/FAIL` 后退出 |
| `WHITEBOX_MENU_PAGE=<solo\|mp\|join\|room>` | 直接打开指定菜单页,配合 SHOT 截取任意一层 UI |
| 联机四件套 | 见《10·七》(`WHITEBOX_HOST` / `JOIN` / `HOSTJOIN` / `PORT`) |

教学自检包含14项确定性断言，覆盖货架朝向、错误大件误装车后的恢复、训练黄牛真实往返偷货，以及无人机静置后仍留在车斗并可被轮盘选中。测试脚本运行联机回归时使用独立端口17788，避免与玩家正在运行的默认7788端口实例互相干扰；正式游戏端口不变。

无头模式下关键里程碑(开局/结算/对局结束)会以 `[headless]` 前缀打到stdout,供脚本断言。
数值旋钮集中在各脚本顶部常量,便于快速调参。

## 五、为什么角色技能必须有专门的自检

无头模拟里没有人按键,`char_skills.gd` 的每一行都不会被执行——不做 `WHITEBOX_CHARTEST`
的话,三个角色技能在自动化测试里**等于零覆盖**,任何重构都可能悄悄改坏而 CI 全绿。

`char_probe.gd` 因此构造了确定性的靶子与攻方,逐条断言:

| 覆盖对象 | 断言要点 |
|---------|---------|
| 贴地冲撞 | 蓄力前摇 → 冷却 → 自身+20代价 → 命中徒步者+55 → 命中即中断突进 |
| 压弯 | 抓地×1.2 生效、**换角色后必须复位**(防被动泄漏)、体力系数在红线内 |
| 扎马步 | 免疫撞击失衡、车斗锁死一件不掉、反击30-50、**仍然可被偷**(弱点也要守住) |
| 余光 | 朝我冲来才报警、背身离开不报警、非马德胜无预警 |
| 全网最低价 | 生成促销减速区、范围内对手减速、李洋本人免疫、自身+20代价、冷却 |
| 爆款嗅觉 | 20米外仍亮壳且显示品名、非李洋在12米外看不到(通用版削弱已生效) |

> 这类"弱点断言"(扎马步仍可被偷、非专属角色拿不到被动)与正向断言同等重要:
> 平衡设计里的**代价与弱点也是需求**,回归时同样不能被改掉。
