# 09 · 界面交互与表现

> 项目:疯抢星期五 | 文档集v1.0 | 对应游戏版本v0.13 | 2026-08-06 | 状态:已立项

---

## 一、键位总表

| 键 | 功能 |
|------|------|
| 鼠标 | 第三人称自由视角(默认捕获,Esc开关) |
| F | 抓住/放开购物车(侧翻自动扶正) |
| W/S(推车) | 沿车头前进 / 刹车·倒车 |
| A/D(推车) | 转向(车速越快越有力,倒车反打) |
| WASD(徒步) | 移动,方向跟随镜头 |
| Shift | 冲刺(即按即用,耗体力) |
| E | 拾取;手有货且在自己车旁=放入购物车;长按=搜货架0.8s/偷无主车1.2s |
| R | 放下手中物品 |
| 鼠标左键 | 肘击(朝镜头方向,无CD耗4体力) |
| 鼠标右键 | 掷水瓶(CD8s) |
| Q | 找货雷达(CD10s) |
| 空格 | 稳住·1秒格挡车撞(CD2.5s) |
| F1 | 开发者模式 / 回车 | 结算后重开 |

## 二、相机

第三人称跟随(枢轴+弹簧臂防穿墙),鼠标环绕,俯仰-66°~+20°;推车时跟随购物车。**涉及本机玩家的碰撞触发相机震动**(强度随车速,平方衰减);联机时只震当事玩家所在的机器。

## 三、HUD布局

- **左上**:购物清单面板(按分区分组,爆款专区置顶;入车标绿划线;实时状态与库存)+已结算得分
- **顶中**:大号倒计时+阶段名(打烊冲刺变橙、宽限变红)
- **中下**:红色粗体情境提示(F推车/按住E搜货…)+长按进度条
- **左下**:技能状态行(Q雷达·右键水瓶·空格稳住 就绪/冷却)+加长版体力槽(绿)/失衡值槽(橙),标注全名
- **右下**:三行红色粗体键位速查
- 教学模式另有顶部绿色大字分步指引

## 四、超市广播(节目效果核心)

**乡土大喇叭横幅**:所有播报以"★超市大喇叭★ ×××"格式,84号大红字+亮黄描边,从右向左**破屏滚动**,带歪扭摆动与呼吸缩放;多条排队播放。

**官方口吻整活文案**(事件触发,带12-15秒防刷屏冷却):

| 事件 | 播报 |
|------|------|
| 玩家被偷 | "请看管好您的随身物品与购物车,商品遗失本店概不负责哦~" |
| 玩家行窃 | "监控室提示:卖场内出现'顺手牵羊'行为。本店对此表示:抓到算你的~" |
| 玩家倒地 | "有顾客在卖场中央选择'平躺'。本店祝他早日站起来,继续消费~" |

| 保洁拖地 | "拖把所到之处寸步难行,请各位顾客小心地滑~" |

另有开业欢迎、限时特价、打烊倒计时系列(见《02》)。

## 五、碰撞与动作表现

- **拟声词飘字**:80号粗体大字,"哐当!!/咣!!!/duang~!!/嘭!!!"随机开头;撞行人追加"人仰马翻!/鞋都撞飞了!/菜篮子保卫战失败!"等
- **双手小球**:所有角色两只球形手,四姿态(走路摆臂/推车扶把/翻找扒拉/托举搬运);肘击时后拉蓄力→猛捅→拳头膨胀2倍
- 倒地为白盒布娃娃平替(弹跳式倒伏),正式版升级物理布娃娃
- 关键反馈飘字:偷窃得手、大妈夺回、水瓶落地"哗啦!!"、水渍干涸、雷达锁定数量等

## 六、开始界面

大红标题+Slogan;按钮:开始游戏/教学关卡;局域网联机区(常显本机IP,创建房间/IP输入+加入房间/主机"开始对局"按钮+人数显示);开发者选项(NPC数量滑块);版本号常显(vX.Y与协议版本双校验)。
