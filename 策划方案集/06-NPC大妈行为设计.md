# 06 · NPC大妈行为设计

> 项目:疯抢星期五 | 文档集v1.1 | 对应游戏版本v0.14 | 2026-08-07 | 状态:已立项
>
> **身份定位**:大妈是**真顾客**——东西是她们自己要用的,所以买齐了还会继续补清单
> (购物欲无底洞)。玩家则是投机者,只把货当筹码。两种动机抢同一批爆款,这是本作
> 冲突的根源之一。

---

## 一、定位

大妈是**环境压力主体**与半个对手:人手一辆购物车、一张与玩家高度重叠的清单,会开车、会抢、会偷、会撞、会报复、会结账。数量0-10可调(默认8)。

## 二、清单与"购物欲无底洞"

- 每人5项:**3项从玩家清单抽取**(联机取全体玩家清单并集)+2项随机常规
- 清单买齐**自动补1-2个新目标**(上限9项)——大妈永远"还想要点什么",全程保持攻击性
- 头顶实时字条"想要:A、B、C(等N样)",买齐变绿;白盒可读性设计,正式版可改弱化

## 三、行为状态机(决策优先级)

1. **装车**:手里有货先回车装车(人在车上则直接入斗)
2. **冲撞(RAM)**:任何人的车里有我想要的→18米内开车冲刺怼上去(撞击走《05》失衡表);得手冷却6秒,失败3.5秒
3. **偷窃**:没人看管的车里有我想要的→停车、下车、1.2秒抽走(优先拿想要的);另有30秒周期的"顺手牵羊"扫描
4. **搜货**:货架上找清单商品(有"目标认领"机制,多只大妈不挤同一货位)→停车→下车→1秒搜取→回车装车
5. **捡漏**:地上散落的想要商品直接捡
6. **随机扫货**:清单无处可抢时随手拿常规品(大件除外),制造库存流失
7. **游荡**

### 被偷追讨(报复机制)

玩家从大妈车里偷走商品→该商品**重新变回她的"想要"**并当场进入追讨(9秒):开车/跑步追逐小偷,追上(1.7米)把商品直接抢回+推搡(+10失衡)。追不上或商品进了小偷车斗→自然转交常规冲撞/偷窃逻辑接管——**记仇但不死缠**。

### 结算与离场

- 每只大妈有随机个人节点(剩50-110秒),届时带着一车货去收银台:排队过闸机→逐件扫码装袋→**开车驶出西侧"出口"离场消失**(不堵收银通道)
- 全程大部分时间在场,终局与玩家一起挤收银台,还原"排队区惨案"

## 四、寻路与防卡

- AStarGrid2D网格寻路(1米格);开车与徒步分别有卡死检测(低于约0.35/0.5m/s才算),先倒车+随机拧向脱困,再不行换目标
- 大妈之间不互相物理阻挡(防人群死锁),与玩家/车辆碰撞正常
- 状态看门狗:同一状态卡超20秒强制重置决策

## 五、方言对话气泡(人格表达)

按事件触发,头顶「」气泡2.5秒,1.2秒防刷屏(摔倒必喊):

| 事件 | 示例台词 |
|------|----------|
| 被车创 | 「哎哟我的老腰!!」「造孽哦——!」「哪个挨千刀的撞我!」 |
| 被偷 | 「贼娃子!放下俺的货!」「抓贼啊!!光天化日!」 |
| 被肘击 | 「打人啦!打人啦!」「妈呀,胳膊肘子恁硬!」 |
| 锁定冲撞目标 | 「你车里那个是俺的!」「站住!莫跑!」 |
| 撞上目标 | 「都是俺的!都是俺的!」「跟俺抢?嫩着呢!」 |
| 摔倒 | 「扶我起来...俺还能抢!」「老婆子跟你拼了!」 |
| 扫货自语 | 「便宜!快囤!」「这个俺屋里正缺!」 |

## 六、事件响应

- **限时特价**:60%概率开车冲向掉落点抢特价箱(特价箱对所有人都算"想要")
- **有人倒地/被偷**:触发超市官方口吻整活播报(带冷却,详见《09》)
