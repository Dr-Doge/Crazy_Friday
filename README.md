## 自动化冒烟测试

改动代码后跑一遍,**stderr 零容忍**:

```powershell
powershell -ExecutionPolicy Bypass -File tools\smoke_test.ps1 -Mode all       # 单机+教学关+联机
powershell -ExecutionPolicy Bypass -File tools\smoke_test.ps1 -Mode single -Full# 全场对局(约5.5分钟)
powershell -ExecutionPolicy Bypass -File tools\smoke_test.ps1 -Mode mp -Clients 5# 6人满员联机
```

脚本自动探测 Godot(也可 `-Godot <路径>` 或环境变量 `GODOT_BIN`),会先 `--import`
注册新脚本的 `class_name`,再多实例并发跑,逐项判定退出码/stderr/里程碑,
日志落在 `test_out/`。判定为 FAIL 时脚本以退出码 1 结束,可直接接 CI。

测试用环境变量钩子:

| 变量 | 作用 |
|------|------|
| `WHITEBOX_AUTOSTART=1` | 跳过开始界面直接单机开局(无头运行默认如此) |
| `WHITEBOX_TUTORIAL=1` | 无头直接进教学关 |
| `WHITEBOX_NPC=<0-10>` | 指定大妈数量 |
| `WHITEBOX_QUIT_ON_END=1` | 对局结算完毕自动退出(全场模拟用) |
| `WHITEBOX_HOST=<N>` | 建房,凑够 N 名客户端立即开局 |
| `WHITEBOX_JOIN=<IP>` | 自动加入指定主机 |
| `WHITEBOX_HOSTJOIN=<IP>` | 先建房再加入,复现真实误操作序列 |
| `WHITEBOX_PORT=<端口>` | 换端口,便于单机多实例 |
| `WHITEBOX_SHOT=<png>` | 运行约2秒自动截图退出(可视化回归) |
| `WHITEBOX_CHAR=<zhao\|ma\|li>` | 指定单人/教学局的角色 |
| `WHITEBOX_CHARTEST=1` | 角色技能自检(27条断言),打印 `RESULT=PASS/FAIL` 后退出 |
| `WHITEBOX_PHYSTEST=1` | 车斗物理压力测试,打印 `RESULT=PASS/FAIL` 后退出 |
| `WHITEBOX_MENU_PAGE=<solo\|mp\|join\|room>` | 直接打开指定菜单页(配合 SHOT 截图做 UI 目视回归) |

## 操作(第三人称+驾驶式推车)

| 按键 | 功能 |
|------|------|
| 鼠标 | 徒步第一人称/驾车第三人称自由视角，采用偏低灵敏度方便准星锁货与瞄准（默认捕获，`Esc` 显示/隐藏鼠标） |
| F | **抓住/放开购物车**;抓住侧翻的车会自动扶正 |
| W / S(推车时) | 沿**车头方向**前进 / 刹车、慢速倒车 |
| A / D(推车时) | 转向(类汽车驾驶,车速越快转向越有力) |
| WASD(徒步时) | 移动,方向跟随镜头 |
| Shift | 冲刺:按下立即提速,耗体力 |
| E | 拾取地上散货 · **手有货且在自己车旁=放入购物车**；准星锁定货架商品后按住拿取(0.8秒) · 偷无主车(1.2秒) |
| R | 把手里的物品放下(丢在脚边) |
| 鼠标左键 | 肘击:**自动朝镜头面朝方向**出肘(无冷却但**每次耗4点体力**,一管体力=25肘;徒步/推车均可) |
| Q | **找货雷达**:绿描边穿墙高亮清单上**还缺**的商品(车里已有同类则全场同类不亮),闪3秒,CD10秒 |
| 鼠标滚轮 | 驾驶购物车时循环选择车内商品；右下轮盘仅在驾驶时显示，并提示爆裂/湿滑/遮挡/定身类型 |
| 鼠标右键 | 驾驶时进入约2米右肩瞄准并显示抛物线，松开投出轮盘商品；脱车时仅缩小第一人称视野至约58°，松开无动作 |
| Ctrl | **稳住**:1秒冲击准备,被购物车撞击不涨失衡(徒步减速,CD2.5秒) |
