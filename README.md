基于策划案《06-疯抢星期五-黑五超市对抗完整设计》第十二节的 Demo 范围搭建的 Godot 灰盒原型。
所有几何体与 UI 均由代码运行时生成,场景文件仅有一个入口节点,便于快速迭代。

## 运行方式

- Godot 4.6+ (本机已有 `Godot_v4.6.2` / `Godot_v4.7` 可执行文件)
- 用 Godot 打开本文件夹(导入 `project.godot`),直接 F5 运行
- 或命令行:`Godot_v4.7-stable_win64.exe --path <本目录>`

## 操作(第三人称+驾驶式推车)

| 按键 | 功能 |
|------|------|
| 鼠标 | 第三人称自由视角(默认捕获,`Esc` 显示/隐藏鼠标) |
| F | **抓住/放开购物车**;抓住侧翻的车会自动扶正 |
| W / S(推车时) | 沿**车头方向**前进 / 刹车、慢速倒车 |
| A / D(推车时) | 转向(类汽车驾驶,车速越快转向越有力) |
| WASD(徒步时) | 移动,方向跟随镜头 |
| Shift | 冲刺:按下立即提速,耗体力 |
| E | 拾取地上散货 · **手有货且在自己车旁=放入购物车**;按住:搜货架(0.8秒) · 偷无主车(1.2秒) |
| R | 把手里的物品放下(丢在脚边) |
| 鼠标左键 | 肘击:**自动朝镜头面朝方向**出肘(无冷却但**每次耗4点体力**,一管体力=25肘;徒步/推车均可) |
| Q | **找货雷达**:绿描边穿墙高亮清单上**还缺**的商品(车里已有同类则全场同类不亮),闪3秒,CD10秒 |
| 鼠标右键 | **掷水瓶**:向镜头方向抛出,落地生成12秒湿滑地面(CD8秒) |
| 空格 | **稳住**:1秒冲击准备,被购物车撞击不涨失衡(徒步减速,CD2.5秒) |
| 回车 | 结算画面后重开一局 |

调试键:`T` 快进1分钟 · `F3` 立即触发限时特价 · `F4` 给自己拉满失衡(测试倒地)

## v0.4 新增机制

- **大妈全员配车**:8名大妈人手一辆购物车,开车扫货、停车搜货架、把货装进自己车斗;**别人车里有她清单上的货就开车冲撞**(玩家和大妈互相都撞),没人看的车直接开偷
- **NPC也要结算**:大妈买齐清单(或打烊前)会开去收银台排队过闸机,逐件扫码装袋走人
- **玩家结算即终局**:过完收银台不能再返场,当场亮结算画面
- **黑五折扣账本**:每件商品都有原价与折扣力度(不显示在头顶),结算画面显示原价合计/折后实付/总计省了多少钱
- **肘击升级**:推车时也能肘击;命中掉落对方**手中随机一件**,并从对方**车斗里肘飞随机一件**
- **双手表现**:所有角色有两个小球做双手,随推车/翻找/搬运/肘击摆动作
- **商品扩充**:27种商品(6必需+18常规+2大件+特价箱)、品牌化命名+名称按商品配色;新增卧式冰柜、端架、促销堆头三种货架形式
- **清单加长**:玩家7项(2必需+4常规+1大件),大妈5项且保证其中2项与玩家重叠——货架前必有一战

## v0.3 机制

- **第三人称相机**:跟随玩家/购物车,鼠标环绕视角,SpringArm 防穿墙
- **车内商品动态重力**:货物入车后进入大重力模式(6倍)牢牢压在车斗里;重力随推车人**失衡值升高而衰减**(失衡满时仅0.55倍)——失衡越高,一次碰撞越容易让全车货飞出去
- **购物车加大**:车斗容积约翻倍(1.05×1.5米,壁高0.62米)
- **驾驶手感**:W永远沿车头方向,A/D打方向,S刹车/倒车,侧向抓地让推车循迹而非漂移

## 本版已实现(对应策划案条目)

- **搜(§五)**:货位每局随机;搜货必须人车分离;手持上限2小件或1大件;抱电视速度减半
- **抢(§六)**:推车冲撞按部位结算失衡(侧45/冲刺侧60/尾25/对头15/撞行人50);失衡满100倒地3秒+翻车甩货;肘击+15并击落手持;失衡脱战3秒后10/秒衰减
- **偷(§五)**:无主车(含玩家停着的车)可被抽货1.2秒/件,车顶弹"!",车主在场收到广播提示;大妈每30秒扫描附近无主车
- **撤(§七)**:2条自助收银道,闸机一次放行一车;通道内免战;1秒/件逐件扫码,扫完的货冻结在收银带不可再失去;提前结算保底
- **打烊(§三/§七)**:10分钟对局;剩2分钟广播打烊并关闭2号通道;时间到进入30秒宽限;宽限结束未扫码商品全部作废
- **大妈NPC(§八)**:8名,持续扫货架造成库存流失,囤到墙角(可以去抄家),特价时60%概率冲锋
- **限时特价(§八)**:随机时间投放2次特价神秘箱,可抵扣清单上任意常规品并+5分
- **环境(§八)**:生鲜区"小心地滑"区域,行走+5/秒失衡、奔跑+10/秒
- **清单与计分(§四/§十)**:清单3项=2必需+1常规;必需品全场库存仅2件;常规10分/必需15/大件25/特价+5
- **购物车物理(§五)**:车斗是真实物理容器,货物真实堆叠;载重越大惯性越大、转向越笨;倒地按比例甩货

## 白盒要验证的三个问题(§十二)

1. 车对车撞击手感是否够"痛快" —— 试:满载冲刺侧撞无主车
2. 被偷/被撞的挫败是否被短局+翻盘兜住 —— 试:停车搜货时让大妈来偷,再用 F3 特价翻盘
3. 脱车搜货的风险节奏是否成立 —— 试:把车停在货架口 vs 藏进过道再徒步往返

## 代码结构

```
scenes/main.tscn        入口(仅一个挂 main.gd 的根节点)
scripts/main.gd         主控制器:计时/阶段/特价/计分/寻路服务
scripts/market_builder.gd 灰盒地图生成(4分区+2收银道+地滑区+寻路网格)
scripts/catalog.gd      商品目录/分区/计分/物理层常量
scripts/item.gd         商品刚体(货架冻结/手持/自由/已扫码 四态)
scripts/cart.gd         购物车刚体(物理车斗/撞击部位结算/偷窃接口)
scripts/actor_base.gd   角色基类(失衡/倒地/手持/肘击)
scripts/player.gd       玩家(推车驾驶/情境交互/长按通道)
scripts/granny.gd       大妈NPC(扫货/囤货/偷车/特价冲锋,AStarGrid2D寻路)
scripts/checkout.gd     收银通道(闸机/免战/逐件扫码)
scripts/slippery_zone.gd 地滑区
scripts/hud.gd          HUD(清单/计时/双条/广播/结算面板)
```
