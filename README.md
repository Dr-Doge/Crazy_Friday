## 运行方式

- Godot 4.6+ (本机已有 `Godot_v4.6.2` / `Godot_v4.7` 可执行文件)
- 用 Godot 打开本文件夹(导入 `project.godot`),直接 F5 运行
- 或命令行:`Godot_v4.7-stable_win64.exe --path <本目录>`

## 操作(第三人称+驾驶式推车)

| 按键 | 功能 |
|------|------|
| 鼠标 | 第三人称自由视角(默认捕获,`Esc` 显示/隐藏鼠标) |
| F | **抓住/放开购物车**;抓住侧翻的车会自动扶正 |
| W / S(推车时) | 沿**车头方向**前进 / 刹车、慢速倒车 |
| A / D(推车时) | 转向(类汽车驾驶,车速越快转向越有力) |
| WASD(徒步时) | 移动,方向跟随镜头 |
| Shift | 冲刺:按下立即提速,耗体力 |
| E | 拾取地上散货 · **手有货且在自己车旁=放入购物车**;按住:搜货架(0.8秒) · 偷无主车(1.2秒) |
| R | 把手里的物品放下(丢在脚边) |
| 鼠标左键 | 肘击:**自动朝镜头面朝方向**出肘(无冷却但**每次耗4点体力**,一管体力=25肘;徒步/推车均可) |
| Q | **找货雷达**:绿描边穿墙高亮清单上**还缺**的商品(车里已有同类则全场同类不亮),闪3秒,CD10秒 |
| 鼠标右键 | **掷水瓶**:向镜头方向抛出,落地生成12秒湿滑地面(CD8秒) |
| 空格 | **稳住**:1秒冲击准备,被购物车撞击不涨失衡(徒步减速,CD2.5秒) |
| 回车 | 结算画面后重开一局 |

调试键:`T` 快进1分钟 · `F3` 立即触发限时特价 · `F4` 给自己拉满失衡(测试倒地)

## v0.4 新增机制

- **大妈全员配车**:8名大妈人手一辆购物车,开车扫货、停车搜货架、把货装进自己车斗;**别人车里有她清单上的货就开车冲撞**(玩家和大妈互相都撞),没人看的车直接开偷
- **NPC也要结算**:大妈买齐清单(或打烊前)会开去收银台排队过闸机,逐件扫码装袋走人
- **玩家结算即终局**:过完收银台不能再返场,当场亮结算画面
- **黑五折扣账本**:每件商品都有原价与折扣力度(不显示在头顶),结算画面显示原价合计/折后实付/总计省了多少钱
- **肘击升级**:推车时也能肘击;命中掉落对方**手中随机一件**,并从对方**车斗里肘飞随机一件**
- **双手表现**:所有角色有两个小球做双手,随推车/翻找/搬运/肘击摆动作
- **商品扩充**:27种商品(6必需+18常规+2大件+特价箱)、品牌化命名+名称按商品配色;新增卧式冰柜、端架、促销堆头三种货架形式
- **清单加长**:玩家7项(2必需+4常规+1大件),大妈5项且保证其中2项与玩家重叠——货架前必有一战

## v0.3 机制

- **第三人称相机**:跟随玩家/购物车,鼠标环绕视角,SpringArm 防穿墙
- **车内商品动态重力**:货物入车后进入大重力模式(6倍)牢牢压在车斗里;重力随推车人**失衡值升高而衰减**(失衡满时仅0.55倍)——失衡越高,一次碰撞越容易让全车货飞出去
- **购物车加大**:车斗容积约翻倍(1.05×1.5米,壁高0.62米)
- **驾驶手感**:W永远沿车头方向,A/D打方向,S刹车/倒车,侧向抓地让推车循迹而非漂移

## 本版已实现(括号内为对应策划文档编号)

- **搜(03/07)**:货位每局随机;搜货必须人车分离;手持上限2小件或1大件;抱大件速度减半
- **抢(05)**:推车冲撞按部位**双方互吃**失衡(侧45/冲刺侧60/尾25/对头15/撞行人50);失衡满100倒地3秒+翻车甩货;肘击+15并击落手持、肘飞车内随机一件(无冷却,每次耗4体力);失衡脱战3秒后10/秒衰减
- **偷(04)**:无主车(含玩家停着的车)可被抽货1.2秒/件,车顶弹"!",车主在场收到广播提示;大妈每30秒扫描附近无主车;**被偷追讨**:大妈会当场追上来抢回
- **撤(08)**:2条自助收银道**全程开放到打烊**,闸机一次放行一车;通道内免战;1秒/件逐件扫码,扫完的货冻结在收银带不可再失去;提前结算保底但**结算即终局**

- **大妈NPC(06)**:默认8名(开发者面板可调0-10),持续扫货架造成库存流失;清单买齐自动补1-2项("购物欲无底洞",上限9项);特价时60%概率开车冲抢;方言气泡
- **限时特价(02)**:每局随机2次投放特价神秘箱,可抵扣清单上任意未完成常规品并+5分
- **环境湿滑(05/07)**:三来源(开局随机3块 + 保洁定时拖地25秒 + 玩家水瓶12秒);踩入瞬间+12失衡,行走+15/秒、奔跑+30/秒,满载推车最高再乘3倍;水渍到寿命自然蒸发
